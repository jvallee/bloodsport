# Blood and Circus 7.4 beta (preview)

A playable preview of 7.2–7.4 (Bleeding and wound styles, unrest and The Chains Break, moles and covert ops), from branch
`v7.2.0`, served at https://jvallee.github.io/bloodsport/v7-beta/. The live game at the root is 7.1.0.

Not final: 2 of the 22 balance gates fail (full Legacy 37%, gate 40–60%; Heat 3 not yet harder than Heat 1).

It keeps its careers, Codex and Legacy under separate browser storage keys (`bloodsport.v7beta.*`), so it never reads or
upgrades the live game's saves. Remove this folder when 7.4 ships to the root.
