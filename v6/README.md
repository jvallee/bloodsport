# Blood and Circus v6 (frozen)

A playable snapshot of the game as of tag `v6.0` (2026-11-10), served at https://jvallee.github.io/bloodsport/v6/.
New since v5:
- the month is the turn, with a digest of each month, and a season as the default career
- Fortune's monthly draft: fighters, gear, boons and 21 relics
- Legacy XP, an unlock tree, Heat, returning Hall legends, the daily Emperor's Challenge
- a live crowd, Oracle tells and All In at the Death Gate
- a balance pass for seasons, and fixes from playtests LLM-12 to LLM-14

Some new words are still first drafts, waiting for the designer's rewrite (`docs/text-to-rewrite.md`); this copy can be
refreshed in place afterwards.

Do not edit unless asked; the live game is at the repo root. Only change from `v6.0`: v6 keeps its careers, Codex and
Legacy under separate browser storage keys (`bloodsport.v6.*`), so it starts with no careers of its own.
