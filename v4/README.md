# Bloodsport v4 (frozen)

A playable snapshot of the game as of tag `v4.0` (2026-10-27), served at https://jvallee.github.io/bloodsport/v4/.
New since v3:
- three-match tournaments from the Silver Coliseum up
- a year-end purse for the top two houses
- fight items combine (one of each kind per fight)
- Medbay treatment order
- Room, Decor and Gear tabs on each fighter

Do not edit unless asked; the live game is at the repo root. Only change from `v4.0`: v4 keeps its save, Codex and Legacy under separate browser storage keys (`bloodsport.v4.*`).
