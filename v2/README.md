# Bloodsport v2 (frozen)

A playable snapshot of the game as of tag `v2.2` (2026-10-27), served at https://jvallee.github.io/bloodsport/v2/.
Updated from `v2.0` at the developer's request with playtest fixes: no Prestige soft-lock, visible reasons on disabled buttons,
items before Round 1, no animation replays, colored Equip/Unequip, and bug reports (Report a bug / crash reports).
Do not edit except on request; the live game is at the repo root. Only change from `v2.2`: v2 keeps its save and Codex under
separate browser storage keys (`bloodsport.v2.*`), so they can't clash with the live game's.
